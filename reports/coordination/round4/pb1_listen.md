# pb1: LISTENING candidate (NOT gate-passing) next to v1

`pb1` = v1 + `--pause-boundary-only on`: inside a sentence the dub pauses only after punctuation or before a clause word
(and / but / so / which / because / that ...); any other source pause is not reproduced and the phrase runs through it.
Gate vs v1: pauses inside an English phrase much fewer, but the dub drifts from the source timing (see the seconds below) -> NOT published as v2.

Files: `<id>_r4_audio_pb1_LISTEN_over-original.mp4` (whole video), `<id>_r4_audio_v1-vs-pb1_AB.mp4` (excerpts: v1 first, then pb1).

Watch-outs: where a sentence's source pauses are merged, the English phrase can end early and leave ONE long silence (04 0:33.4: a new 7.8 s pause before "and");
that is the price of no pauses inside phrases.
