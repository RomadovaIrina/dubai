# DabAI ML: план работ (пилот + блоки 5–9)

Версия от 28.10.2026. Зона ответственности: пилот (блок 0) и блоки 5–9 ТЗ. Бэкенд, веб и платежи не наши.
Подробный статус каждого пункта лежит в `tz_status.md`.

**Порядок: сначала качество, потом скорость.** Качество включает всё, что в блоках 5–8 влияет на картинку и звук, даже если это «подготовка».
Скорость (норматив ≤ 300 с на минуту видео на одной 5090) идёт отдельной фазой, но уже сейчас держим ≤ 600 с и не
добавляем ничего, что ломает её навсегда.

Правила на всех фазах:
- только коммерчески чистые модели;
- фиксы общие, не под 5 роликов;
- каждый шаг проверяется регрессионным прогоном против прошлой опубликованной версии;
- на просмотр выкладываем WATCH-видео.

**План рассчитан на несколько дней, это не задача на один раз.**

**Сейчас (r7):** только чтобы звук и видео встали красиво:
- 1A пункты 1–3 и 7 (вклейка, швы, рывки, m6);
- 1B пункты 1–3 (мусор в паузах, посадка под губы, Qwen 7B против 14B);
- 1C, субтитры: идёт параллельно на CPU, качество не блокирует.

**Потом, когда качество встанет:**
- 1A пункты 4–6 (поворот головы и pre-check, двое в кадре, перекрытие, мелкое лицо, свет);
- 1B пункты 4–6 (фильтр галлюцинаций, нарезка VAD, больше двух спикеров).
На хорошей базе они закроются легче.

## Фаза 2. Скорость (после принятия качества)
Цель: **≤ 300 с на минуту видео на одной 5090**, без потери качества фазы 1.
1. Профиль по этапам на всех 5 роликах и на тестовом видео. Найти три самых дорогих места.
2. LatentSync:
   - число шагов;
   - батч;
   - мост (bridge);
   - обрабатывать только кадры, где рот должен двигаться.
   Каждая настройка проверяется по детектору рывков.
3. Аудио:
   - перевод под длительность: число кандидатов, гибрид 7B / 14B;
   - Chatterbox батчем.
4. Видеопамять: что можно держать в памяти постоянно, а что выгружать по этапам. Обновить отчёт 0.4.
5. Перемерить пилотные 0.5 и 0.11 на финальном пайплайне.

## Фаза 3. Закрыть хвосты ТЗ (пилот и блоки 5–9)
1. **Письменно в допсоглашение:**

2. **Рабочий образ (5.1):** пересобрать под чистый пайплайн без запрещённых весов, веса на томе. Отдать инфраструктуре.
3. **Языки кроме EN:** роутинг (6.5), ChatterboxVC (7.4), OpenAI TTS как донор с rate limiter (7.5), CER по языкам (12.2).
4. **Интерфейс для бэкенда:**

   - выход: mp4 + статус SUCCESS / PARTIAL_SUCCESS / ERROR + проценты по шагам + флаги («нет лица», «много поворотов», «больше двух спикеров»).
