   - Блоки 1–4 (бэкенд, веб, платежи) не наши.

   - CodeFormer (8.3, 0.6, 0.7) убран, у него NC-лицензия. Реставрации лица сейчас нет.
   - RetinaFace R50 и InsightFace buffalo_l (5.4, детекция лиц) убраны по лицензии.
   - LatentSync 1.6 остаётся: OpenRAIL++, ты одобрила.
4. **Qwen.**

   - Сейчас: 7B Q8_0 на GPU.
   - Обсуждаем 14B, идёт замер скорости и качества.
