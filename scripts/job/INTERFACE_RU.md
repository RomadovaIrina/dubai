# DabAI: как бэкенду запускать ML-задачи (кратко)

Полное описание на английском: [INTERFACE.md](INTERFACE.md). Схемы JSON: `job.schema.json` (вход) и `status.schema.json` (выход).

## Главное
- **Одна задача — одно видео.** На выходе: дублированное видео, субтитры, `metrics.json` и статус.
- **Один воркер — одна видеокарта (RTX 5090, 32 ГБ) — одна задача за раз.** Остальные ждут в очереди по порядку. Две задачи на одной карте не влезут в память.
- **Как вызывать:**
  - HTTP-сервис (FastAPI) — основной вариант;
  - командная строка `python scripts/job/dabai_job.py job.json`.

## HTTP
| Запрос | Что делает |
|---|---|
| `POST /jobs` | Ставит задачу в очередь. Ответ 202: `{job_id, status: "QUEUED", queue_position}`. 422 — ошибка в параметрах (в ответе список всех ошибок). 409 — такой `job_id` уже есть. |
| `GET /jobs/{id}` | Статус. Опрашивать раз в 3–5 секунд. |
| `GET /jobs/{id}/events?after=N` | События (смена шага, каждые +5 %, финал), удобно для экрана ожидания. |
| `GET /jobs/{id}/files/video` (`subs`, `metrics`, `log`) | Готовые файлы. |
| `DELETE /jobs/{id}` | Отмена задачи. |
| `GET /health` | 200 — воркер готов принимать задачи, 503 — нет (нет GPU, весов или места на диске). |
| `GET /version` | Версии интерфейса, кода и образа. |

- **Токен:** если задан `DABAI_API_TOKEN`, все запросы, кроме `/health`, передают заголовок `Authorization: Bearer <токен>`. Токен выбираете вы, мы ключей не создаём.

## Вход (главные поля)
```json
{"job_id": "a1b2c3", "input": "https://...presigned-R2-url... или путь к файлу", "target_lang": "en",
 "mode": "quality", "subs": {"enabled": true, "style": "yellow", "lang": "dub", "karaoke": true},
 "watermark": {"enabled": true, "text": "DabAI", "corner": "br", "opacity": 0.6}}
```
- `mode`:
  - `quality` — основной режим, одобренный по качеству;
  - `fast` — дешевле по GPU примерно на 25–35 %, синхрон чуть слабее.
- `target_lang`: 22 языка. `en` — основной, проверенный путь.
- `polyglot`: свой язык для каждого предложения.
- `lipsync: "off"`: только перевод голоса, без губ.
- Ссылку на файл можно давать с подписью: параметры после `?` нигде не сохраняются и в логи не попадают.

## Статусы
| Статус | Что значит | Видео есть? | Предложить возврат? |
|---|---|---|---|
| QUEUED / RUNNING | Ждёт / работает: `step`, `progress_pct`, `eta_s` | — | — |
| SUCCESS | Всё хорошо | да | нет (кроме «лицо не найдено») |
| PARTIAL_SUCCESS | Результат с оговорками, например губы не синхронизированы на части кадров. Текст для пользователя на RU и EN — в `warnings` | да | да |
| ERROR | Ошибка. Код в `error.code` (таблица ниже), текст на RU и EN, признак «можно повторить» | нет | да |
| TIMEOUT | Задача слишком долгая и остановлена | нет | да |

- Поле `refund_suggested` подсказывает, когда вернуть минуты. Само списание и возврат делает бэкенд.

**Коды ошибок:**

| Код | Что случилось |
|---|---|
| E_BAD_REQUEST | Ошибка в параметрах |
| E_INPUT_NOT_FOUND | Нет файла |
| E_DOWNLOAD_FAILED | Не скачалось (можно повторить) |
| E_INPUT_TOO_LARGE | Слишком длинное или большое видео |
| E_INPUT_UNREADABLE | Нет видео или звуковой дорожки |
| E_NO_SPEECH | В видео нет речи |
| E_AUDIO_FAILED | Не получилась озвучка |
| E_NO_OUTPUT | Не собралось итоговое видео |
| E_TIMEOUT | Задача остановлена по времени |
| E_CANCELLED | Задача отменена |
| E_WORKER_RESTART | Воркер перезапустился во время задачи (можно повторить; задачи в очереди не теряются) |
| E_INTERNAL | Внутренняя ошибка |

## Образ (`infra/docker/`)
- **Сборка:** `bash infra/docker/build.sh`. Скрипт только собирает образ и печатает команды выкладки в реестр. Выкладываете вы: у нас нет доступа к реестру.
- **Весов в образе нет.** Они лежат на отдельном томе, около 24 ГБ. Том заполняется один раз командой `fetch-models` (нужен `HF_TOKEN` для pyannote). При старте воркер ничего из интернета не скачивает.
- **Профиль образа — открытое решение (продукт и юристы), значения по умолчанию нет.** Его задают при сборке обязательным параметром `DUB_PROFILE`:
  - `clean` — без CodeFormer, фон отделяется Spleeter. Коммерчески чисто, но рот выглядит иначе (сравнение — в клипах A/B);
  - `current` — как сейчас на серверах: с CodeFormer и htdemucs. Это осознанное отступление от лицензий, его приняли 29.10. Некоммерческие части подключаются с отдельного тома и в сам образ не попадают.
  - Без явного профиля образ не собирается и не запускается.
- Какие компоненты некоммерческие или под вопросом: `reports/experiments/r15-tz/LICENCES_PROD_PATH.md`.
- **Самопроверка:** `docker run --gpus all ... check`. Пробная задача: `... smoke clip.mp4`.

## Ресурсы на один воркер
- Видеокарта на 32 ГБ (пик 27,5 ГБ).
- Оперативная память от 64 ГБ.
- Диск: 24 ГБ под веса, плюс рабочее место на время задачи (цифры — в REPORT.md). После задачи рабочие файлы удаляются.
- Время и GPU-секунды на минуту видео — в REPORT.md.

## Что не наше
Очередь между несколькими воркерами (Redis / Celery), баланс и возвраты, письма, загрузка результата в R2, автоскейлинг (блок 10).
